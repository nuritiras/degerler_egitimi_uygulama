
# 🌟 Değerler Dünyası – Flutter Mobil Uygulaması

Flutter kullanılarak geliştirilen **Değerler Dünyası**, dokuz farklı değeri renkli kartlar aracılığıyla tanıtan basit bir mobil uygulamadır.

Bu proje, 11. sınıf Bilişim Teknolojileri Alanı, Yazılım Geliştirme Dalı öğrencilerinin Mobil Uygulamalar dersinde öğrendikleri Flutter widget'larını pekiştirmeleri amacıyla hazırlanmıştır.

## 📱 Uygulama Hakkında

Uygulamada günlük hayatımızda önemli bir yere sahip olan dokuz değer tanıtılmaktadır:

- Sabır
- Yardımlaşma
- Dürüstlük
- Sorumluluk
- Merhamet
- Paylaşma
- Adalet
- Hoşgörü
- Güven

Her değer, kendine ait renkli bir kart içerisinde ikon, başlık ve açıklama metniyle gösterilmektedir.

Kartlar üç satır ve üç sütun şeklinde düzenlenmiştir.

## 🖼️ Uygulama Görünümü

Uygulamanın ekranında:

- Üst bölümde Değerler Dünyası başlıklı AppBar
- Sol tarafta menü ikonu
- Sağ tarafta arama ve seçenekler ikonları
- Gövde bölümünde 3 × 3 kart düzeni bulunmaktadır.

## 🛠️ Kullanılan Teknolojiler

- Flutter
- Dart
- Material Design

## 📚 Kullanılan Flutter Widget'ları

Bu projede aşağıdaki Flutter widget ve özellikleri kullanılmıştır:

| Widget / Özellik | Açıklama |
|---|---|
| MaterialApp | Uygulamanın temel yapısı |
| Scaffold | Ana ekran iskeleti |
| AppBar | Uygulamanın üst menüsü |
| Container | Değer kartlarının oluşturulması |
| Center | İçeriğin ortalanması |
| Row | Kartların yatay yerleştirilmesi |
| Column | Kartların dikey yerleştirilmesi |
| Icon | Kartlara simge eklenmesi |
| Text | Başlık ve açıklamaların gösterilmesi |
| child | Tek bir alt widget yerleştirilmesi |
| children | Birden fazla alt widget yerleştirilmesi |
| body | Ana ekranın gövdesi |

## 🚀 Projeyi Çalıştırma

### 1. Depoyu bilgisayarınıza indirin

```bash
git clone https://github.com/nuritiras/degerler-dunyasi.git
```

### 2. Proje klasörüne girin

```bash
cd degerler-dunyasi
```

### 3. Paketleri kontrol edin

```bash
flutter pub get
```

### 4. Uygulamayı çalıştırın

```bash
flutter run
```
